# Product Specs Index

## Purpose

This directory stores product specs and user workflow descriptions.

Internal product specs should be written in English. End-user-facing documentation, onboarding text, help text, and UI copy examples should be written in Russian unless explicitly requested otherwise.

## Specs

- `new-user-onboarding.md` — first-run and onboarding workflow.

## Add a product spec when

- a user-facing workflow changes;
- new settings or admin actions are introduced;
- subscription behavior changes;
- onboarding, migration, or troubleshooting behavior changes;
- UI changes alter user expectations.
