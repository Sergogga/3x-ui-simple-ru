# Core Beliefs

## Purpose

This document records project principles that should remain stable across implementation changes.

## Principles

1. Security-sensitive behavior must be explicit.
2. Runtime and deployment changes must be conservative.
3. The project should stay reasonably compatible with upstream `MHSanaei/3x-ui`.
4. User-facing Russian documentation and UI copy must be clear, direct, and operational.
5. Xray configuration changes must be reviewed for compatibility and rollback safety.
6. Installer, updater, Docker, and systemd changes require extra caution.
7. Documentation is part of done, not an optional follow-up.

## Language split

- Internal agent/developer instructions: English.
- User-facing responses and Russian admin documentation: Russian.
- UI copy examples for Russian users: Russian.
